# DESIGN SYSTEM

Canonical design system: [docs/rebuild/04-design-system.md](docs/rebuild/04-design-system.md).  
Runtime Fusion additions: `ui/fusion.css`.

All application domains inherit the same semantic tokens, RTL typography, spacing, accessibility, responsive behavior, and interaction rules. Vendored/embedded workspaces may retain internal functional layouts but cannot own a second global brand, sidebar, topbar, or theme system.
