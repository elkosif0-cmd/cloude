# التحكم بالكمبيوتر عن طريق ChatGPT

برنامج بايثون يجعل ChatGPT يرى شاشتك ويتحكم بالماوس ولوحة المفاتيح لينفّذ أي مهمة تكتبها له.

## كيف يعمل
1. يأخذ لقطة للشاشة ويرسلها إلى ChatGPT مع مهمتك.
2. يرد ChatGPT بأوامر: تحريك الماوس، نقر (يسار/يمين/مزدوج)، سحب، تمرير، كتابة نص (يدعم العربية)، اختصارات لوحة المفاتيح، وتشغيل أوامر الطرفية (اختياري).
3. ينفّذ البرنامج الأوامر، ثم يأخذ لقطة جديدة، ويتكرر ذلك حتى تنتهي المهمة.

## التثبيت
```bash
pip install -r requirements.txt
cp .env.example .env      # ثم ضع مفتاح OpenAI داخل .env
```
- **ماك:** اسمح للطرفية من «إعدادات النظام ← الخصوصية والأمان» بصلاحيتي «تسجيل الشاشة» و«إمكانية الوصول».
- **لينكس:** يعمل على X11. ثبّت: `sudo apt install python3-tk python3-dev xclip`. جلسات Wayland تمنع التحكم، فاختر جلسة Xorg عند تسجيل الدخول.
- **ويندوز:** يعمل مباشرة.

## الاستخدام
```bash
# مهمة واحدة
python agent.py "افتح المتصفح وابحث عن سعر الذهب اليوم"

# وضع المحادثة: اكتب المهام واحدة تلو الأخرى
python agent.py

# اطلب موافقتي قبل كل أمر (مستحسن في البداية)
python agent.py --confirm "افتح المفكرة واكتب فيها: مرحبا"

# اسمح بأوامر الطرفية أيضاً
python agent.py --allow-shell "أنشئ مجلداً اسمه تقارير على سطح المكتب"

# نموذج آخر أو عدد خطوات أكبر
python agent.py --model gpt-4.1 --max-steps 80 "..."
```

## الأمان
- **إيقاف طارئ:** حرّك الماوس بسرعة إلى أي زاوية من زوايا الشاشة، أو اضغط `Ctrl+C` في الطرفية.
- أوامر الطرفية معطّلة إلا مع `--allow-shell`.
- لقطات شاشتك تُرسَل إلى OpenAI، فأغلق أي شيء خاص قبل التشغيل.
- كل خطوة تكلّف طلباً للنموذج مع صورة؛ البرنامج يُبقي آخر 3 لقطات فقط في المحادثة لتقليل التكلفة.
