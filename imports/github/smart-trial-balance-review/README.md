# ⚖️ ميزان المراجعة الذكي — مجلس المراجعين AI

تطبيق ويب عربي (RTL) يدير دورة مراجعة كاملة لميزان المراجعة بمجلس مراجعين افتراضي مبني على **Google Gemini**:

1. **إدخال الميزان** — رفع Excel/CSV أو لصق يدوي أو نموذج جاهز، مع التحقق من التوازن.
2. **الربط التلقائي بالمعايير** — كل بند يُربط بمعايير IFRS/IAS (كما تعتمدها SOCPA)، وبالضغط على شارة المعيار تظهر: تفاصيله، دوره في المحاسبة، علاقته بهذا البند تحديدًا، آخر تطوير لمعياره، ومصادره الرسمية.
3. **جولات مراجعة بالمجلس** — ثلاثة مراجعين افتراضيين (الفني المحاسبي · الامتثال والإفصاح · المخاطر والأدلة):
   - الجولة الأولى: مراجعة الميزان + آراء المجلس + درجة خطورة + **طلب مستندات محددة**.
   - ترفق المستندات (PDF/صور/Excel/CSV/TXT) → يراجعها المجلس ويعطي حكمًا لكل مستند (مقبول / غير كافٍ / مرفوض).
   - إن دعت الحاجة يطلب مستندات إضافية → جولة ثالثة… وهكذا حتى status = «اكتمال».
4. **التقرير النهائي والتحليلات الاحترافية** — رأي ختامي، مؤشرات KPI، رسوم بيانية (توزيع الخطورة، أكبر الأرصدة، تطور الخطورة عبر الجولات)، نسب مالية محسوبة آليًا، مصفوفة تتبع المستندات المطلوبة مقابل المسلَّمة، مصفوفة المعايير المطبقة، طباعة/حفظ PDF وتصدير JSON.

> ⚠️ المخرجات استراحة مهنية تعليمية ولا تُغني عن رأي المحاسب القانوني المخوّل. بيانات "آخر تحديث" في قاعدة المعايير تقريبية — راجع الروابط الرسمية داخل التطبيق.

## 🚀 التشغيل محليًا

لا يحتاج بناء ولا اعتمادات:

```bash
# أي خادم ثابت يكفي
python -m http.server 8080
# ثم افتح http://localhost:8080
```

ثم من تبويب **⚙️ الإعدادات**: ألصق مفتاح Gemini API مجانيًا من <https://aistudio.google.com/apikey> → اضغط «اختبار الاتصال» → حمّل «نموذج جاهز» وابدأ الجولة الأولى.

المفتاح يُحفظ في متصفحك فقط (localStorage) ولا يمر على أي خادم وسيط — النداءات تذهب مباشرة إلى `generativelanguage.googleapis.com`.

## ☁️ 1) النشر على GitHub Pages

```bash
git init && git add . && git commit -m "feat: ميزان المراجعة الذكي"
gh repo create smart-trial-balance-review --public --source=. --push
gh api repos/<USER>/smart-trial-balance-review/pages -X POST \
   -f "source[branch]=main" -f "source[path]=/"
```

يعمل الموقع بعد دقيقة على: `https://<USER>.github.io/smart-trial-balance-review/`

## 🟠 2) النشر على Cloudflare Pages

من مجلد المشروع:

```bash
npx wrangler login          # مرة واحدة فقط
npx wrangler pages deploy . --project-name=smart-tb-review
```

أو يدويًا من اللوحة: [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages → Create → Pages → **Connect to Git** → اختر المستودع → Build command: *(فارغ)* → Output directory: `/`.

> بديل بدون تسجيل دخول (تجريبي ومؤقت): `npx wrangler deploy --temporary`

## ✨ 3) Google AI Studio ([ai.studio](https://ai.studio))

التطبيق متوافق مع نمط "Build" في AI Studio لأنه يستدعي Gemini API مباشرة بالمفتاح:

1. ادخل إلى [aistudio.google.com/apps](https://aistudio.google.com/apps) → **Build** (إنشاء تطبيق).
2. استخدم **Import from GitHub** واختر هذا المستودع (بعد إنشائه في الخطوة 1)، أو الصق محتويات `index.html` في الـ canvas وأضف بقية الملفات بنفس المسارات.
3. داخل AI Studio لا تحتاج حتى مفتاحًا خاصًا؛ يعمل المفتاح المؤقت للبيئة تلقائيًا مع gemini-2.5-flash.
4. زر Share/AI Studio link ينشر نسخة قابلة للمشاركة فورًا.

## 🗂️ بنية المشروع

```
├── index.html              # الواجهة (RTL)
├── css/style.css           # الهوية الذهبية/الورقية
└── js/
    ├── data/standards.js   # قاعدة معايير IFRS/IAS + المصادر والتحديثات
    ├── mapping.js          # ربط البند↔المعيار + التصنيف التحليلي والنسب
    ├── parser.js           # قراءة Excel/CSV/لصق + نموذج متوازن
    ├── gemini.js           # عميل Gemini API (JSON منظّم) + المخططات
    ├── board.js            # مجلس المراجعين: الجولات والمستندات والأحكام
    ├── report.js           # التقرير الختامي + الرسوم والمصفوفات
    └── app.js              # الحالة، التبويبات، الحفظ المحلي، الاستيراد/التصدير
```

## 🔐 الخصوصية

- لا يوجد أي خادم خلفي؛ البيانات في المتصفح.
- عند بدء جولة مراجعة تُرسل نصوص البنود/المستندات المرفقة إلى Google Gemini فقط.
- المرفقات تبقى في ذاكرة الجلسة (زر تصدير الجلسة يحفظ النتائج دون الملفات الثنائية).
