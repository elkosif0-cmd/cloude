# Sector specifications

Detailed sector requirements live here. FOUNDATION.md states the invariant product rules; these files can evolve as sector knowledge deepens.

Priority sectors:
- hospitals / healthcare
- hotels / hospitality
- construction / contracting
- meat
- digital marketing

Other supported sectors include manufacturing, education, bakery, agriculture/farms and general trade.

Each sector spec should cover:
- chart-of-accounts adaptations
- master data
- source transactions and workflows
- posting rules
- costing model
- inventory/receivables/payables where relevant
- management tasks and approvals
- KPIs and reports
- helper tools specialized for the sector
- audit implications
- acceptance scenarios and sample company requirements
