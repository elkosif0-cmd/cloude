# S.KOSIF Knowledge Library

هذه المنطقة مخصصة لمكتبة المعرفة المرجعية للمشروع.

- الكتب توضع تحت `knowledge/books/files/` عند توفر نسخة مسموح بتخزينها.
- الفهرس الرسمي للكتب هو `knowledge/books/catalog.json`.
- قواعد استخدام الـAI للمكتبة موجودة في `knowledge/books/README.md`.
- لا يُعتبر وجود كتاب في المكتبة بديلاً عن المعايير/اللوائح الرسمية الأحدث عند وجود تعارض.
