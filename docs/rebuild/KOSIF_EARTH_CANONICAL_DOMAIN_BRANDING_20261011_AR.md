# KOSIF EARTH — الهوية الرسمية ونطاق التطبيق

**التاريخ:** 11 أكتوبر 2026. **المنتج:** KOSIF EARTH. **المستودع:** `cloude`، الإصدار المرئي الآمن المبني من `main`، دون دمج مسودة الخادم JWT/المراجعة PR #42 أو مسودة تكامل EARTH الموسعة PR #247.

## الرابط الأساسي

**https://earth.kosif.pp.ua/** مرتبط بمشروع Cloudflare Pages الحالي `s-kosif`، بحساب صاحب المشروع الذي يدير المنطقة `kosif.pp.ua`، وذلك بدل مشروع جديد يفقد متغيرات البيئة وأسرار Pages الموجودة. سجل DNS من نوع CNAME `earth.kosif.pp.ua → s-kosif.pages.dev` مع Cloudflare Proxy، وحالة Cloudflare Pages custom domain أصبحت **Active** بما فيها HTTPS.

الروابط القديمة `s-kosif.pages.dev` و`a6eb2e47.s-kosif.pages.dev` هي أسماء URL نشر تاريخية مستقلة لا يمكن تغيير نصها بأثر رجعي؛ تبقى كروابط توافقية، لكن الجديد هو الرابط الرسمي المعروض كـ`canonical` داخل واجهة الدخول. لا تحذف المشروع الأصلي أو تغير قنوات نشره دون دراسة الروابط القديمة.

## تحديث الاسم الحقيقي وليس الغلاف

- `build.py`: تغيير اسم **SQC — Smart Quality Control** الذي كان يُعاد حقنه عند كل بناء، وكذلك description وfavicon والشريط الجانبي، إلى **KOSIF EARTH**.
- `manifest.webmanifest`: الاسم واسم الشاشة الرئيسية والوصف والأيقونات، مع **الاحتفاظ بالاختصارات الخمسة** والأوضاع الثلاثة المحاسبة/المراجعة/الأدوات ومسار التشغيل.
- `unlock.html`: رابط `canonical` الرسمي، شعار الكلمة KOSIF EARTH وFavicon، وعدم المساس بتتابع اختيار القسم/القطاع/الشركة.
- `ui/ds/shell.css` و`ui/ds/sqc.css`: منع الثيمات من فرض لفظ SQC القديم، مع اعتماد الشعار الجديد في الشريط الجانبي.
- `ui/layouts/shell.js`: favicon ديناميكي جديد.
- ملفات `ui/art/brand/kosif-earth-icon.svg` و`kosif-earth-wordmark.svg` وPNG بأحجام 192 و512 لتثبيت PWA على الجوال.
- **مهم:** أسماء الملفات والمفاتيح البرمجية القديمة مثل `skosif_ledger_v1` و`SQC_BUILD_MODE` واسم مشروع Pages `s-kosif` تبقى كما هي لأن تغييرها بلا هجرة يسبب فقد البيانات أو تعطل عمليات البناء؛ هي **معرّفات توافقية غير ظاهرة في اسم المنتج**.

## الاختبارات والحدود

- بناء Preview محلي ناجح **194 مدخلًا** بلا `dist/secure`.
- دستور المنصة **18/18 ناجح**.
- اختبارات اسم المنتج وربط اختصاراته/الأقسام **18/18**.
- Microsoft Edge سطح مكتب وجوال **18/18** اختبار واجهة دخول مع ثلاث بوابات، أصول SVG/صور، وعدم overflow أو أخطاء JavaScript.
- الاختبار الشامل الموازي واجه إخفاقًا سابقًا في اختبار قراءة خطوط/Shadow DOM تحت ضغط التوازي، **ولا يوجد ادعاء بأن المجموعة الكاملة نجحت**. ينبغي إعادة CI/اختبار الأداء بعد معالجة قيود الـRunner؛ فشل بعض GitHub Actions سبق حدوثه **قبل تنفيذ خطواتها**.
- مسودة `chatgpt/kosif-earth-manual-merge-20261010` وPR #247 لا تزال تحتوي تغييرات كثيرة وخطورة بيانات وشهادات JWT غير مكتملة، **ولا تُدمج** لمجرد تغيير الرابط.
- هذا إصدار هوية/واجهة فقط؛ القدرات التشغيلية الموجودة أصلًا في `main` لم تُحذف أو يُعاد توليد بياناتها؛ كل وظائف الفروع التاريخية غير المثبتة لم تُعتمد ضمن الإصدار.

## التحقق بعد رفع main

تأكد من:
1. استجابة HTTPS `earth.kosif.pp.ua` وعنوان الصفحة **KOSIF EARTH**.
2. `/manifest.webmanifest` يحمل `short_name: KOSIF EARTH` وخمسة shortcuts وأيقونات حديثة.
3. `/app-safe.html` يحتوي الاسم الجديد وليس `app-name: SQC`.
4. Cloudflare Pages deployment على `main` ناجح ومطابق للـSHA الجديد.
5. عدم حذف أو إعادة توجيه روابط النشر التاريخية قبل متابعة مستخدميها.
