## هيكل تقرير المراجعة المستهدف (تحسينات بعد تثبيت الضوابط)
1. **Dashboard تنفيذ الارتباط**: شركة ونطاق، 10 مراحل مهنية (A01–A10)، عدد جولات الأدلة المنعقدة، عدد جلسات النماذج الفعلية مع وسم تشغيل حي/حتمي/غير متاح، ونسبة تغطية الأدلة.
2. **تقرير الفروقات بين الجولات**: ما أضيف/ألغي من أدلة، قضية جديدة/أغلقت، مخاطر تغير تصنيفها، طلبات مستندات متأخرة/غير متاحة، وسبب إعادة فتح قرار سابق.
3. **مصفوفة أدلة ونتائج**: معيار ساري/نسخته ← خطر ← إجراء ← عينة ← مستند ببصمة ← نتيجة ← ملاحظة ومبلغ ← موافقة بشرية.
4. **تقرير مجلس AI**: طلب كل عضو، المزوّد والنموذج، الاستجابة أو الفشل، مبرراته ومصادره، الخلاف الحقيقي، منع تضخيم آراء متشابهة، قرار Jev استشاري، قرار مراجع بشري منفصل.
5. **التقرير الختامي الاحترافي**: نتيجة الرأي وقيود النطاق وKAM عند الانطباق، الأخطاء غير المصححة، ملاحظات الرقابة الداخلية وخطاب الإدارة، سجل توقيع وتاريخ إصدار ونسخة غير قابلة للتعديل، التصدير المدعوم بمصدر مثبت.
