# USER JOURNEYS

## Daily manager
Unlock → Command Center → attention item → open source record → review → approve/action → audit event.

## Customer sale
Search customer → open customer → create order/invoice → add items → payment/split payment → save → stock event → collection status → printable/shareable receipt.

## Inventory count
Inventory → start count → enter physical quantities → review variances → approve adjustments → movement ledger + audit record.

## Procurement
Low-stock alert → supplier comparison → purchase order → receiving → actual waste/quality → stock receipt → supplier history.

## Monthly income statement
Finance → Income Statement → select month → choose sold materials/quantities or load recorded sales → calculated material cost → add other expenses → review gross/net profit → save/print/export.

## Pricing
Catalog → item → cost breakdown → simulate price → request approval → approve → publish price → audit record.

## Jev decision
Attention item or Ask Jev → frozen evidence snapshot → deterministic metrics → Jev judgment/recommendation → alternatives/uncertainty → user approval → action → outcome recorded.

## Audit
Accounting & Audit → create/open engagement → ingest source → map/reconcile → analytical tests → issues/evidence → reviewer council → report/issuance.
