# User Journeys

## Daily operation
Unlock → Command Center → see exceptions → choose contextual action → complete operation → confirmation/audit record.

## Product / pricing
Command search → catalog item → inspect cost and selling price → simulate/sensitivity if needed → save/approve → offer/order/export.

## Inventory / purchasing
Command Center alert → inventory → reorder suggestion → supplier/purchase order → receiving/yield check → stock/quality trail.

## Customer / collection
Search customer → customer context → open balance/order history → collection or new transaction → report/contact.

## Finance
Command → cash/receivables/ZATCA/report → filter period/context → review → export.

## Audit
Accounting & Assurance → engagement command view → documents/evidence → issues → council/adjustments → financials → report/issuance.

The audit journey uses one product shell; audit stages are local workflow context, not a second global navigation.

## Mobile rules
All primary journeys must remain usable on iPhone/Safari with safe-area support, no page-level horizontal overflow, scrollable sheets and no background scrolling under modal command surfaces.
