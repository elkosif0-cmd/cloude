# NEW INFORMATION ARCHITECTURE

## Primary navigation — Daily Work

1. **Command Center**
   - today, attention queue, recent activity, quick actions.
2. **Sales & Customers**
   - orders, invoices/POS, collections, customers, offers.
3. **Inventory & Production**
   - stock, counts, expiry/FIFO, suppliers, receiving, production/blending, traceability, dry aging.
4. **Finance**
   - cash flow, income statement, expenses, receivables/payables, profitability.
5. **Catalog & Pricing**
   - products/materials, boxes, costs, pricing, approvals.

## Advanced tools

1. **Intelligence**
   - Jev today, ask Jev, monitor, simulate, recommendation history.
   - sales/customer intelligence, sensitivity and risk.
2. **Accounting & Audit**
   - audit workspace, evidence, issues, statements/entries, analytical tests, standards lab.
3. **Analysis Labs**
   - carcass/yield/NRV, product matching, reconciliation, advanced reports.
4. **System**
   - users/roles/capabilities, integrations, data center, audit log, health, backup/migration.

## Contextual navigation

Entity screens use a common pattern:
- Overview
- Activity
- Financial/stock context
- Related records
- Actions

No floating launchers. Rare actions live in command palette or contextual menus.

## Global search / command palette

`Ctrl/Cmd + K` searches:
- customers
- products
- orders
- invoices
- reports
- capabilities/tools
- settings/actions

Results are grouped by entity type and can execute commands when permitted.
